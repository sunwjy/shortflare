# shortflare

Idempotently install or upgrade a Shortflare Instance in a Cloudflare account:

```sh
npx shortflare@latest deploy
```

The package includes pinned Wrangler, prebuilt Workers, D1 migrations, and a
verified release manifest. See the repository's
[deployment guide](https://github.com/sunwjy/shortflare/blob/main/docs/deployment.md)
for token permissions, non-interactive usage, upgrades, diagnosis, and recovery.
